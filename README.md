# LadCall Beta para Windows

Versão de **testes** do app desktop do [LadCall](https://ladcall.io). Abre o ambiente de testes (staging), com contas
separadas da produção, e recebe as novidades antes do app estável.

**Baixar:** [LadCall-Beta-Setup.exe](https://github.com/TwoGuysDev/ladcall-desktop-beta/releases/latest/download/LadCall-Beta-Setup.exe)
(Windows 10 ou 11, 64 bits). Instala ao lado do LadCall estável, sem administrador, e se atualiza sozinho.

O app estável fica em [ladcall-desktop-releases](https://github.com/TwoGuysDev/ladcall-desktop-releases).
Este repositório só guarda os arquivos das versões beta (`.exe`, `.blockmap`, `beta.yml`).
